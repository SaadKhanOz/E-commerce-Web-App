# E-commerce Microservices (MERN + Docker)

This repository will host a microservices-based e-commerce platform built with the MERN stack. The initial focus is on containerization with Docker and setting up a clean project structure, followed by testing with Jest.

## Getting Started
- Initialize Git and connect to GitHub
- Run Docker services with Compose (to be added)
- Add services incrementally (auth first)
